Features

Everything you need to track,
bill, and get paid

Built for contractors and consultants who bill by the hour and want accurate, automatic tracking without lifting a finger.

⏱

Automatic Detection

Reads Claude Code's JSONL logs and detects sessions automatically. No manual timers, no browser extensions. Just works.

⚡

Live Dashboard

See which projects are active right now with real-time processing indicators. Know exactly when Claude is thinking vs idle.

🖥

Floating Widgets

Always-on-top mini windows showing per-project status. Stay visible across desktops and full-screen apps so you never lose track.

💲

Stripe Invoicing

Auto-generate invoices from billable sessions and send them through Stripe. ACH-only mode keeps processing fees under $5 per invoice.

🧠

AI Summaries

Claude Haiku turns commit messages and session data into plain-language descriptions for invoice lines and reports. Falls back to git commits if no API key.

👥

Clients & Projects

Organize work by client with hourly rates. Toggle billable/non-billable per session. Auto-detect ticket IDs from your commits and roll them up by day.

📈

Analytics Dashboard

Ten drag-and-drop widgets: daily hours, billable earnings, hours by client and project, peak hours, token usage, work vs idle, and more.

💰

Estimated API Cost

See what your usage would have cost at pay-as-you-go API rates, broken down per model with cache pricing included. Know exactly what your subscription saves you.

📄

Reports & Export

Session breakdowns, daily summaries, and period rollups with AI-written overviews. Export as Markdown, CSV, or PDF, or copy to clipboard.

🔔

Desktop Alerts

Native toast notifications when Claude finishes processing. Configurable sounds and idle thresholds. Visible over full-screen apps, including Citrix VDI sessions.

🛡

Secret Scanner

Detects 40+ patterns of API keys, tokens, passwords, and private keys in your JSONL files. Optional auto-redaction and custom patterns.

🔄

Auto-Updates

Built-in updater pulls new versions from GitHub releases and prompts to install. Background checks keep you on the latest with zero effort.

🔒

100% Local

No telemetry. No cloud. No accounts. SQLite stays on your machine. The only outbound calls are the Anthropic and Stripe APIs you opt into.

For Contractors

Get paid faster.
Keep more of every dollar.

Stop losing 3% of every invoice to credit card processing fees. ClauTime auto-generates invoices from your tracked hours and sends them through Stripe with ACH bank transfer, so you keep nearly all of what you earned.

The card-fee tax on contractors

Most invoicing tools push your client to pay with a credit card. That's convenient for them and expensive for you. On a typical $5,000 monthly invoice, credit card fees eat $145 before you see a dollar.

Stripe's ACH bank-transfer rate is capped at 0.8% / $5 max per charge. ClauTime's invoice flow has a one-click ACH-only toggle that removes the credit card option entirely, so clients pay via bank transfer by default and you keep the difference.

  • Test/sandbox mode to dry-run invoices before sending
  • Auto-sync of paid/open status — no manual reconciliation
  • Hosted invoice URL and downloadable PDF, branded with your Stripe account

How It Works

Zero configuration required

ClauTime reads what Claude Code already writes. No setup, no integrations, no overhead.

01

Claude Code writes logs

Every conversation is recorded as JSONL files in ~/.claude/projects/. This happens automatically — it's how Claude Code works.

02

ClauTime detects sessions

Smart gap-based detection with tool-aware idle timeouts. Tracks prompts, tokens, models, and timing across all your projects.

03

You bill and get paid

Assign sessions to clients, generate timesheets, and send Stripe invoices with one click — ACH-only if you want to skip the credit card fees.
