Features

Everything you need to track
your Claude Code work

Built for developers who bill by the hour and want accurate, automatic tracking without lifting a finger.

⏱

Automatic Detection

Reads Claude Code's JSONL logs and detects sessions automatically. No manual timers, no browser extensions. Just works.

⚡

Live Dashboard

See which projects are active right now with real-time processing indicators. Know exactly when Claude is thinking vs idle.

📈

Analytics

Session trends, token usage, AI vs human time, gap analysis. Customizable dashboard widgets to understand your workflow.

👥

Client Management

Assign projects to clients, mark work as billable or non-billable, and generate reports ready for invoicing.

📄

Reports & Export

Session breakdowns, daily summaries, and period reports. Export as Markdown to clipboard or file. AI-powered summaries optional.

🔔

Desktop Alerts

Get notified when Claude finishes processing. Configurable sounds, volume, and alert thresholds per project.

🛡

Secret Scanner

Detects 50+ patterns of API keys, tokens, and credentials in your JSONL files. Auto-redaction available. Protect your secrets.

🖥

Floating Widgets

Always-on-top mini windows showing per-project status. See time and activity at a glance without switching windows.

🔒

100% Local

No telemetry. No cloud. No accounts. All data stays on your machine in a local SQLite database. Your data is yours.

How It Works

Zero configuration required

ClauTime reads what Claude Code already writes. No setup, no integrations, no overhead.

01

Claude Code writes logs

Every conversation is recorded as JSONL files in ~/.claude/projects/. This happens automatically — it's how Claude Code works.

02

ClauTime detects sessions

Smart gap-based detection with tool-aware idle timeouts. Tracks prompts, tokens, models, and timing across all your projects.

03

You get actionable data

Assign sessions to clients, generate billable reports, and understand exactly how your AI-assisted development time is spent.
