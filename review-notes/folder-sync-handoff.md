## Agreed scope

- Optional user-selected Google Drive/OneDrive/other synced folder; SQLite stays local. No hosted service or mandatory account.
- One person switching computers sequentially. No distributed billing locks or multi-user permissions in v1.
- Preserve imported time, tokens, edits, and invoice history when source logs are deleted, providers disabled, or folders excluded. Only explicit history deletion propagates a tombstone.
- Permanent project IDs, editable per-computer folder mappings, and Source Machine information. Moving/renaming folders preserves history.
- Canonical activity deduplication and shared session policy prevent copied logs or different OS timezones from changing totals.
- Sessions from every machine count toward invoices. Sync saved invoices, billed-work links, and cached status. API keys stay local and are entered separately on each PC. Import never triggers Stripe writes or paid AI calls.
- Full requirements, conflict handling, recovery, migration rules, and acceptance scenarios are in the plan.
